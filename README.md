# Forge

Local marketing studio for multiple mobile apps. Next.js, TypeScript, Tailwind, SQLite, local files, Sharp and FFmpeg. Uses your ChatGPT-authenticated Codex CLI; no API key, hosted database or cloud server is required.

## Run

Node.js 22.13+ and npm:

```sh
cd "/Users/dipinchopra/Downloads/Forge Marketing Studio"
npm install
npm run dev
```

Open http://127.0.0.1:3000. For production, `npm run build -- --webpack` then `npm start`. Both servers bind to localhost. Telemetry is disabled.

Install Codex CLI and run `codex login` with ChatGPT. If necessary, set `FORGE_CODEX_BIN` in `.env.local`. Settings checks the connection. Generation requires internet and consumes subscription allowance. Forge removes API-key environment variables and disables shell/web tools for its ephemeral, structured Codex requests. Low reasoning effort, smaller image context and batched drafting reduce work. Ollama remains unimplemented.

Install FFmpeg (`brew install ffmpeg`) for local MP4 rendering and video metadata. Restart Forge after adding migrations or changing environment settings.

## Create: slideshow and carousel

- The saved 12-angle bank loads immediately for each app/output. Before a Codex bank exists, profile-based starters are explicitly labeled. **Refresh 12 with Codex** produces fresh short hooks, angles and outlines; fresh generation is not instantaneous.
- Direction is optional. Select multiple angles; up to three drafts share one Codex call. Existing projects are reused on retry. Keep the page open for batch processing; stop takes effect after the current group.
- Choose Hook–Problem–Solution–CTA, AIDA, PAS or Hero. Each draft has six slides. Prompts require sixth-grade language, short headlines and brief supporting text.
- Choose 9:16, 4:5 or 1:1. The editor can change the ratio later.
- Public Pinterest imagery can be sourced by a visual topic; app/store screenshots remain available for feature proof. Alternatively use only the existing library.
- Template dumps are excluded from this workflow on the server and in image pickers.
- Editor: edit copy, move text vertically using a slider/presets, replace images from a visual library picker or upload, duplicate/delete slides, save and export one/all PNGs. Multiple PNG downloads may require browser permission. ZIP export remains future work.
- CTA: a brand logo/icon, uploaded App Store graphic, or store screenshot, plus “Download on the App Store”. Choose a replacement in the editor when desired.
- TikTok Sans Bold with white fill and black outline. The font and OFL license are in `public/fonts`.

## Public Pinterest crawler

No Pinterest API or account cookies are used. Forge attempts public pin and board search HTML, then public DuckDuckGo HTML discovery, including when Pinterest search fails. It tries up to three subject-preserving queries and reads at most twelve public boards and reads actual pin image records from public HTML. Images retain pin links and source attribution. Avatars and generic page imagery are not substituted for missing pins. Candidates are ranked against concrete query terms in their original pin captions; unmatched images are rejected. Search queries are not added to image descriptions. Automatically sourced pools exclude unrelated Pinterest images from previous projects. Labeled contact sheets show Codex each concept’s candidates, including in bulk drafts, so it can pair visible subjects with copy. Caption matching and AI visual judgment are useful filters, not a guarantee of relevance.

Results are cached locally for 24 hours; downloaded images deduplicate by content. Public availability does not establish reuse rights; attribution records explicitly note that rights are unverified. Empty logged-out search shells, verification pages, blocking, markup changes or missing results produce a clear error. Verification pages are not bypassed, and public searches cannot be guaranteed for every topic. A specific public board URL can also be supplied in Create and stays attached to generation; fetching a board no longer switches subsequent generations to local-only mode. No access controls are bypassed.

## Hook + Demo

A compact, separate tool inside Create. Choose the number of outputs (1–50) and audio mode, then **Make videos**. All local hook/demo clips are included by default; an optional collapsed list lets you exclude footage.

- Random pairs without repeating until the available pair combinations have been used.
- Every output contains the complete hook clip followed by the complete demo clip. No trims, duration controls or added CTA segment. FFmpeg alone handles stitching.
- One saved hook line is overlaid throughout the hook clip. Only text can be generated by Codex, using the explicit **Add with Codex** action.
- Saved text banks live in `forge-data/settings/text-bank-<appId>.json`. Each bank accepts up to 500 entries. Paste one line per entry, or append 25–500 new lines with Codex in saved batches of 25. Existing lines are preserved and generated duplicates are removed. Randomization and rendering make no AI calls.
- Original audio is the default; muting is optional. Missing audio is padded with silence. Files are re-encoded to compatible H.264/AAC, 1080×1920, without shortening either video.
- 64px result previews in a compact responsive grid, twelve per page, with modal previews and direct downloads. Keep the page open during batch rendering; **Finish pending** resumes saved drafts. Earlier trimmed drafts remain stored but are excluded from this full-length workspace.

Put clips in `Apps/<app>/Hook + Demo/Hooks/` and `Apps/<app>/Hook + Demo/demo/`, then sync.

## Template Swipes

A separate format using complete Display Image(s) folders. Each directory is one set, sorted numerically. Different dumps never mix, even when template numbers repeat. Canvas Assets are ignored. File membership remains separate from content deduplication.

- All template folders in one searchable, compact list. Each carousel stays on one row with 18px thumbnails. **Pick random** selects a fresh batch; **Select all** includes every visible folder, up to the 50-video batch limit.
- Saved hooks are selected automatically. Choose 1–10 variations per template or randomize a specific hook; no AI call is needed for these variations.
- One headline stays fixed for the entire swipe sequence. The artwork moves horizontally; text does not move or change between slides.
- Optional three-second CTA end card after the final slide: selected brand/store image, editable CTA text, and “Download on the App Store”. Disable it to export only the swipe sequence.
- Choose fixed custom text or vary saved text across the batch. Hook and CTA variation controls are independent; varying CTAs cycles through different saved lines per template. Randomization makes no AI call.
- Silent 1080×1920, 30fps H.264 MP4. No zooms or random slide mixing. Results are compact 64px thumbnail grids, twelve at a time, alongside the template list on desktop, with timestamps and a persistent **Latest batch** marker/filter.
- **Preview / edit** opens a small portrait popup for both video tools. Change hook text or vertical position, replace Hook + Demo source clips at full length, and re-render repeatedly. Template CTA text and brand images are editable there too. The CTA end-card tab independently positions the headline and App Store line; these coordinates are saved in the plan and applied by FFmpeg.
- MP4 playback supports streaming byte ranges and HEAD requests for seeking and browser compatibility. `node scripts/verify-video-editor.mjs` checks real renders, edits, hook-bank variations, clip replacement, and playback responses against the running local app.

## Slide editing and project browsing

**Change image** opens one dialog with upload and a paged local image library. An uploaded or selected image immediately replaces the current slide image. **Crop image** allows dragging a rectangle; the crop is saved as normalized coordinates and never modifies the source file. Reset restores the full image. Remaining canvas space is black.

Text is white TikTok Sans with a black outline; no gradient is placed behind it. Text position, copy and aspect ratio remain editable. The Projects page shows actual first-slide canvas previews, including saved text and crops, in a responsive 4–5 column gallery, with 24 projects per page.

## Apps, Library and Lurker

App CRUD and App Store URL import work locally. Current screenshots come from the live regional listing’s own media shelves, not stale lookup screenshots or recommendations. Refreshing a profile registers current screenshots in Library; older files remain available to existing projects.

Sync `Apps/<app folder>/` from Library or Create. Originals stay untouched. Files are copied and deduplicated per app. Unchanged local files are skipped using saved size/mtime. Scanning is bounded at 5,000 media files, 16 directory levels and 150 MB per file; hidden files and symlinks are skipped. Shared app selection is remembered between the main workspaces.

Lurker saves social URLs even when retrieval fails. Available captions, user notes and optional screenshots provide evidence for Codex’s format analysis. Missing evidence is reported; Forge does not claim to watch inaccessible videos. Remix generates 12 ideas for the chosen app/output. Template remix opens Template Swipes to choose a complete design rather than randomly combining assets.

## Storage and verification

SQLite and media live in `forge-data/`; override with `FORGE_DATA_DIR`. Startup runs SQL migrations. Back up the entire directory with Forge stopped. `Apps/`, `Common Assets/` and `forge-data/` are excluded from Git. Source deletion and automatic media cleanup are not implemented.

```sh
npm run typecheck
npm test
npm run build -- --webpack
```

Tests cover CRUD, migrations, asset isolation, template membership, ordered sets, full-length clip enforcement, Pinterest parsing, caption rasterization, saved edits and bulk idempotency. HTTP/FFmpeg smoke scripts preserve sample output:

- `scripts/verify-http.mjs`: pages and temporary App CRUD.
- `scripts/verify-simple-video.mjs`: random pairing, full clip duration, fixed headline and branded CTA rendering; no AI calls.
- `scripts/verify-bulk.mjs`: general local render smoke check, no AI calls.
- `scripts/verify-pinterest.mjs`: public discovery and download, no API.
- `scripts/verify-copy.mjs`: real 12-angle bank and project; consumes two Codex requests.
- `scripts/verify-fast-batch.mjs`: two projects in one Codex request, using the saved test bank.

Important implementation files:

- `migrations/005_bulk_workflows.sql`: source membership, attribution, Hook + Demo records.
- `src/lib/server/template-sets.ts`: exact template grouping.
- `src/lib/server/template-videos.ts`: deterministic swipe renderer.
- `src/lib/server/hook-videos.ts`: random pairing, full-length checks and stitching.
- `src/lib/server/pinterest.ts`: bounded public HTML crawler.
- `src/lib/server/idea-bank.ts`, `creatives.ts`, `bulk-projects.ts`: cached ideas, structured drafts and batched generation.
- `src/components/project-editor.tsx`, `src/lib/slide-canvas.ts`: editable image/text/ratio controls and PNG export.

Still to build: durable jobs across server/browser restarts, a cross-app campaign queue, bulk ZIP/download packaging, richer layout families, automatic semantic asset indexing, local Ollama, and automated discovery/clustering. No changes have been pushed to GitHub.

The video workspaces use scoped CSS in `src/components/video-workspace.module.css`, bounded content panes and collapsed optional settings. Popup previews have explicit portrait dimensions and text sizing instead of container-relative font sizing. Safari interaction still requires verification in a connected browser.

Slideshow and carousel currently share the six-slide editor and PNG export pipeline; their defaults differ (9:16 for TikTok slideshows, 4:5 for Instagram carousels). They do not yet have separate motion/export behavior.
